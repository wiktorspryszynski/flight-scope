# Flight Tracker Project - Tech Stack

## 🖥️ Frontend

### Framework / Language
- React
- TypeScript
- Vite
- TailwindCSS

### Maps / Visualization
- WebGL (3D rendering / GPU)
- Mapbox GL JS (2D/3D maps, textures, basemap)
- Leaflet (optional, simpler maps)
- Cesium JS (3D globe, “wow” effects)

### 3D / Animations
- Three.js (core 3D rendering)
- react-three-fiber (Three.js integration with React)
- GLTFLoader (loading 3D airplane models)
- deck.gl (heatmaps, trajectories, thousands of markers)
- PixiJS (2D animations / alternative to deck.gl)

### Data Visualization / Charts
- Recharts
- Chart.js

### Realtime Communication
- WebSocket / socket.io-client

---

## ⚡ Backend

### Framework / Language
- Python
- FastAPI
- Django (optional)
- Flask (optional)

### Database / Storage
- PostgreSQL (historical flight data)
- Redis (cache, live data, websocket state)

### ML / Data
- NumPy
- Pandas
- scikit-learn
